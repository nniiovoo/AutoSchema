# Real-paper reference for polymer cards

Prepared 28 October 2026. Three published experimental papers were read to prepare a small, portable, source-linked test for the new polymer-card workflow. The response records are **manually curated assistant reference inputs**, not model outputs. They test source preparation, the polymer-only retention rule, nested record validation and card rendering. They do not measure live extraction accuracy or exhaustive recall.

These selected entities are not an exhaustive annotation of all polymer mentions in the full articles. For example, other control polymers, binders or background references may legitimately be discovered in a full-paper extraction. A model's additional entity cannot be called a false positive merely because it was not selected for this small reference.

Purchased polymers, low-performing controls, polymeric precursors and incomplete descriptions remain eligible. A polymer's source role is recorded rather than used as a performance or completeness cutoff. These are assistant scientific interpretations checked against the primary context, not authenticated human ground truth.

## Important field-to-specimen checks

**Pei2024:** Methods separately report polymer synthesis, commercial reagents and subsequent lithium-salt electrolyte preparation. The matrix feed molar ratio1:2.4:1 is distinct from the polymer:LiFSI mass ratio2:1. Conductivities2.4×10⁻⁴,6.5×10⁻⁵ and1.2×10⁻⁵S/cm at30°C belong to the BHDS/LiFSI, HDI/LiFSI and PEO/LiFSI specimens respectively. The lower-conductivity HDI polymer remains retained under the new rule. PEO and PTMG have commercial-source evidence; purchased starting materials do not make the author-synthesized matrices commercial. The sparse PTMG card remains retained even where monomer, synthesis or property facts were not selected. [Pei Methods and Fig3](https://doi.org/10.1038/s41467-023-43467-w).

**Chen2021:** The precursor copolymer and subsequently cross-linked network remain distinct identities. The selected mechanical paragraph reports5MPa for precursor tensile strength and21MPa after crosslinking; neither value is assigned to an arbitrary salted, wetted or differently specified membrane. The original BA/BMA naming inconsistency is preserved. This fixture deliberately does not use the ambiguous wet-state conductivity series or resolve the12μm/15μm thickness discrepancy. Unreported test details remain absent rather than guessed. [Chen §§2.3–2.5 and3.1](https://doi.org/10.3390/polym13234155).

**Guo2020:** P3 is one formulation in the PDMS–SS–IP–BNB polymer family; the family name is not blindly treated as an alias for every P1–P7 formulation. The93%±3% healing efficiency after2h at room temperature is **fracture-strain recovery**, whose definition appears in the mechanical-test Methods. It is not tensile-strength recovery. The demonstrated conductor uses liquid EGaIn and P3 as an encapsulation/supporting layer, so the metal's electrical recovery is not assigned to neat P3. The reactive PDMS precursor remains a polymer while its commercial origin is left not found in the selected main-text coverage. [Guo Results, Polymer synthesis and mechanical-test Methods](https://doi.org/10.1038/s41467-020-15949-8).

## Portable artifacts and original-evidence boundary

- [papers.json](../examples/polymer_cards/papers.json) points to local JSON packs of selected, original text passages with stable chunk IDs and section/paragraph locators. No network or model credential is needed for replay.
- [curated-responses.json](../examples/polymer_cards/curated-responses.json) contains the manually assigned identities, classifications and six information groups. Every included fact carries its parent entity and evidence reference; every property names its specimen.
- [reference.json](../examples/polymer_cards/reference.json) freezes retention decisions and selected semantic expectations.
- [provenance.json](../examples/polymer_cards/provenance.json) records original/excerpt hashes, licenses, source URLs, DPAL matches, coverage and curation limitations.

The excerpt file hash verifies the bytes actually passed to the code. `original_document_sha256` records the separately archived original XML; it must not be confused with the excerpt file hash. JSON source packs describe selected coverage rather than pretending to contain a whole paper.

Successful quote containment establishes that the quoted span occurs in the supplied source. It does not establish that a model assigned the span to the right scientific quantity, specimen or chemical class. The manually checked reference is intended to expose those attribution errors separately from structural validation. None of this fixture changes the older application-screening profile, reference, source receipts or actual software evaluation.
